# Waqar Coffee Platform

منصة وقار كوفي كاملة: واجهة متجر React، API آمن، قاعدة بيانات SQLite، وDashboard لإدارة الطلبات والمنتجات والمنيو والمحتوى.

## التشغيل محليًا

1. انسخ `.env.example` إلى `.env` وضع كلمة مرور قوية وقيمة عشوائية لـ `SESSION_SECRET`.
2. ثبّت الحزم وشغّل النظام:

```bash
npm install
npm run dev
```

- الموقع: `http://127.0.0.1:8000`
- الداشبورد: `http://127.0.0.1:8000/admin`
- الـAPI المحلي: `http://127.0.0.1:8000/api`

في وضع التطوير، React والـAPI يعملان من نفس السيرفر على بورت `8000` لتجنب تعارض البورتات أو إرسال طلبات الإدارة لخدمة أخرى.

بيانات الدخول تُقرأ من `ADMIN_EMAIL` و`ADMIN_PASSWORD` داخل ملف `.env` غير المتتبع. لا تضع بيانات دخول حقيقية في المستودع، وغيّرها قبل أي نشر فعلي.

## وظائف الداشبورد

- عرض الطلبات وتفاصيل العميل والمنتجات.
- تغيير حالة الطلب من جديد إلى مكتمل أو ملغي.
- عرض إثبات الدفع الخاص بفودافون كاش وInstaPay.
- إضافة وتعديل وحذف المنتجات وصورها وأسعارها وخياراتها.
- إضافة وتعديل وحذف مشروبات المنيو والأسعار.
- تعديل عنوان المتجر وأرقام واتساب والدفع وعنوان الـHero.
- تعديل روابط السوشيال ورفع لوجو لكل منصة.

## الحماية

- كلمات المرور مشتقة باستخدام `scrypt` مع salt فريد.
- جلسات Admin عشوائية مخزنة كـSHA-256 في قاعدة البيانات.
- Cookies من نوع HttpOnly وSameSite Strict وSecure في الإنتاج.
- CSRF token لكل جلسة على كل عملية كتابة.
- Rate limiting لتسجيل الدخول وإنشاء الطلبات.
- Validation مركزي باستخدام Zod.
- إعادة حساب الأسعار من قاعدة البيانات؛ إجمالي العميل غير موثوق.
- فحص توقيع ملفات PNG/JPEG/WebP وحد أقصى 5MB.
- صور إثبات الدفع خارج المسار العام ولا تُعرض إلا للأدمن.
- Security headers باستخدام Helmet.

## الاختبارات والفحص

```bash
npm run lint
npm test
npm run test:coverage
npm run test:e2e
npm audit --audit-level=high
npm run build
docker build -t waqar-coffee .
```

الـCI يشغّل lint وAPI tests والبناء وnpm audit وبناء Docker على كل Push وPull Request.

## التشغيل بـDocker

```bash
docker compose up --build
```

الخدمة تعمل على `http://127.0.0.1:8787` مع Volumes مستقلة لقاعدة البيانات وإثباتات الدفع.

## الهيكل

- `src/admin` — واجهة الإدارة.
- `src/components` — واجهة العميل.
- `server` — API، قاعدة البيانات، الجلسات والحماية.
- `storage/public` — صور المنتجات والسوشيال العامة.
- `storage/private` — إثباتات الدفع الخاصة، غير متتبعة.
- `tests` — اختبارات API وPlaywright E2E.
- `screenshots` — صور فعلية ناتجة عن اختبارات المتصفح.
